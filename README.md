# snes-rm2k-docs

Documentation for the tools that port RPG Maker 2000 games to the Super
Nintendo. It is an [mdBook](https://rust-lang.github.io/mdBook/): the
sources are in `src/`. Every push to `main` builds it and publishes it to
GitHub Pages (`.github/workflows/pages.yml`); `mdbook serve` previews it
locally, in `book/`, which is not committed.
