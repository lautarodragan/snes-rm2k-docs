# Research

A research page is a dated study: "on such a day, at such a commit, we
measured this". Each one answers a question someone asked at the time —how
much the game weighs, which commands are missing, how far other games get—,
says how every number was obtained, and usually ends with a recommendation.

**A research page is a snapshot, and it is not updated.** The top of each
page says the date and the commit of what it measured, and its numbers are
from that moment. If something changed, it gets measured again and a new
study is written; the old one stays as it was. So the paths, file names and
tools a study mentions are those of its day, and some of them no longer
exist: that is not a mistake to fix, it is the record of what was there.

That is the difference with the pages that describe how the port works
today: those have to be up to date, or they lie, and whoever changes what
they describe changes them in the same commit. A study is never touched.

The studies were written in Spanish and translated later, as they were. The
file names keep their Spanish slugs, so that the code and the task history
that cite `docs/research/<name>.md` still find them by name. The commit
hashes are from snes-rm2k unless a study says otherwise; "ABL at …" is a
commit of the A Blurred Line port. The research about A Blurred Line itself
lives with the port.
